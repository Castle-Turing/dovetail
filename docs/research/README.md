# docs/research — the full research reports

Point-in-time research and literature reviews commissioned during
design work, one markdown file per report, landed here so the record
stays readable by anything that can read files — never left as a
rendered page on a hosting service the repo cannot reach.

How these relate to `docs/backlog/`: backlog entries carry the
compressed, decision-relevant versions, kept current as decisions
consume them — they stay authoritative for what the project decided to
do. Files here are the full reports behind those entries: the complete
argument, the sources, and each report's own account of its limits.
They are historical records and are not updated as the project moves.

Each report states its own trust discipline — which claims were
verified against sources and which are unverified recall — and a
reader quotes nothing onward without checking it. Empty so far.
